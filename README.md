# tools

個人網頁工具集，透過 GitHub Pages 發佈：https://slufergo-gh.github.io/tools/

- `voice-note/` 行車語音筆記
- `remote-camera/` 遙控相機
- `read-aloud/` 文件朗讀
- `fluid-art/` 流動畫（GPU 流體模擬，倒顏料＋吹風）
- `page-notes/` 逐頁筆記（每頁旁邊寫筆記，自動暫存、存檔/讀檔、多檔切換，輸出 Word）
- `pdf-notes/` PDF 註解整理（抽出 PDF 上的註解，排成上圖下逐條註解的 Word）
- `slide-notes/` 投影片筆記（PDF 每頁轉圖排進 Word，留筆記空間）
